# Git 커밋 & README 작업 내역 기록 규칙

1. **한글 커밋 메시지 작성**:
   - Git 커밋 시 커밋 메시지는 반드시 직관적인 한글로 작성한다.

2. **사전 pull 및 동기화**:
   - 커밋 및 푸시 작업 전 원격 저장소로부터 `git pull`을 실행하여 최신 코드를 풀다운하고 충돌 없이 동기화한다.

3. **README 일자별 작업 내역 기록**:
   - 모든 작업 단위마다 `README.md`의 `📅 작업 내역 (Changelog)`에 일자(YYYY-MM-DD)와 간략화된 작업 요약을 작성하고 함께 커밋한다.
